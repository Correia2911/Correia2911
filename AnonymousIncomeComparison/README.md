# Anonymous Income Comparison

A beginner C# console program that calculates the estimated annual income for two people and reports whether Person 1 earns more than Person 2.

## Requirements

- .NET 10 SDK

## Run

From the repository root, run:

```powershell
dotnet run --project .\AnonymousIncomeComparison\AnonymousIncomeComparison.csproj
```

Enter each person's hourly rate and hours worked per week when prompted. The program estimates annual income using 52 weeks per year.

> This is a practice program. It assumes the entered values are valid numbers and does not account for taxes, overtime, or time off.
